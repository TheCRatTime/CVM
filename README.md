# CVM
**CVM** - Virtual Machine that writed in C.

## Description
This is a small virtual machine with assembler syntax.
Have **compiler**, **decompiler** and **runner**.

### Features
- **C89**/**ANSI C** code standard.
- **Tools**: have compiler from text, decompiler
  from opcodes and runner.
- **Zero warning**: compiles with this flags:
  **-Wall -Wextra -Weverything -Werror -pedantic
  -Wno-unsafe-buffer-usage -Wno-padded -Wno-undef**

### Build
Needed:
- C Compiler
- CMake 3.10 and greater
- GNU Make

```bash
cmake -B build
cd build/
make
```
